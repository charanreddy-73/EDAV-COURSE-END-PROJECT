# Indian Fuel Price Trend Analysis

An exploratory data analysis project studying how **petrol and diesel prices change over time** across selected observations in India. Built as an EDAV course-end project, it uses Python data analysis libraries to explore fuel price patterns and present key findings through visualizations.

## What's inside

- **Explore the data:** Load and inspect fuel price records and summarize key fields.
- **Clean and transform:** Check missing values, convert dates, and prepare data for analysis.
- **Compare and summarize:** Compare petrol and diesel prices and calculate summary statistics.
- **Study trends:** Examine changes in recorded fuel prices over time and compare selected metropolitan cities.
- **Visualize insights:** Use line charts, bar charts, histograms, scatter plots, and other visualizations to explore price patterns.

## Tools

`Python` · `NumPy` · `Pandas` · `Matplotlib` · `Seaborn`

## Run the project

1. Keep `Fuel_Price_Trend_Analysis.ipynb` and `fuel_prices.csv` together.
2. Open the notebook in **Jupyter Notebook**, **JupyterLab**, or **Google Colab**.
3. Install the required libraries if needed:

   ```bash
   pip install -r requirements.txt
   ```

4. Update the CSV path in the data-loading cell if necessary, then run the notebook cells in order.
